# Solaire's Adventure
This project was made for the Multimedia Technology Course of Athens University of Economics and Business
As a team who worked in the past, we have chosen a diffrent challenge!

This is what video games inspired us to do. The following game is based on the already existent video game called Dark Souls created by Ubisoft.

It combines both our passion for the game and the traditional 2d games we have all played in the past.

The game was created using Unity and C#. For the design we used Piskel App, an excellent online pixel art tool which can create images and even sprites.

The music and the sound effects were made from scratch by us. 

The goal of this game is to defeat the enemies, collect as many coins as you can and of course reach and defeat the final boss.

## Controls of the game

- Space --> Jump
- Run Left + Right --> A + D Key
- Attack --> Mouse Left Click
- Menu Hovering --> Up + Down Arrow OR W + S Key
- Menu Selection --> Enter Key
- Pause Menu --> Escape Key

To test the game simply download the .exe file and start playing

For more details you can always check the final report of the game (Written in Greek :P)
